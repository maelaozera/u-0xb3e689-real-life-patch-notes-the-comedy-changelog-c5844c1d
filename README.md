Entry for the make.fun bounty [Real-Life Patch Notes: The Comedy Changelog](https://make.fun/bounty/u-0xb3e689-real-life-patch-notes-the-comedy-changelog-c5844c1d).

A one-line software patch note for a bug in real life / human biology, in the terse register of a real release note. `main.ts` (Node 22, stdlib only) writes the selected line deterministically to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).

> v4.2.0: Fixed a bug where the bladder sent urgent alerts at 3am, then reported zero items pending on arrival.

Run it with:

```sh
node main.ts
```
